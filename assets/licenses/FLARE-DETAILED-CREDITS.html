Credits

This listing is our best-faith, hard-work effort at accurate attribution, sources, and licenses for everything in Flare. If you discover an asset/contribution that is incorrectly attributed or licensed, please contact us immediately. We are happy to do everything we can to fix or remove the issue.

License

Flare's code is released under GNU GPL v3 and the art is released under CC-BY-SA 3.0. Later versions allowed for both licenses.

If you are interested in using any of the game's code or assets under a different license, please contact me or the appropriate artist listed below.

Code

Engine code credits can be found at the Flare Engine project page
