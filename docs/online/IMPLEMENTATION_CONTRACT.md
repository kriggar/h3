# Third-person reboot contract

The new active runtime lives in `game/online`. The previous game is retained in Git history. Preserve the exact `mara.glb` SHA-256 in `catalog.gd`; do not modify the character, sword, animations or material sources. New authored world, progression, interface and server simulation.

## Shared API

`catalog.gd` is plain RefCounted data. Coordinates: X/Z horizontal, Y up; character +Z forward. All replicated positions are three-element arrays. IDs in snapshots are strings, including player peer IDs. `ground_y`, `blocked`, `move_slide` are shared deterministic terrain/building collision. Physics-only decoration must not create invisible server obstacles.

`realm.gd` RefCounted owns authoritative state. Public `state: Dictionary`, `events: Array`, `add_player(id:int, name:String, profile:Dictionary={})`, `remove_player(id:int)`, `input_player(id:int, command:Dictionary)`, `act(id:int, command:Dictionary) -> Dictionary`, `step(dt:float)`, `snapshot() -> Dictionary`, `profile(id:int) -> Dictionary`. Commands: input `{move:[x,z],yaw:float,jump:bool}`; action `{type:"ability",id:"strike",target:"fang_1"}`, `{type:"interact",id:"steward"}`, `{type:"quest",id:"road"}` (accept or claim), `{type:"gather",id:"bloom_1"}`, `{type:"loot",id:"..."}`, `{type:"equip",id:"watch_blade"}`, `{type:"attribute",id:"might"}`, `{type:"buy",id:"potion"}`, `{type:"respawn"}`. Validation rejects invalid IDs, types, non-finite numbers, distances, resources, dead actors, cooldowns, missing ownership. All state changes stay on server. Attribute IDs might/vitality/spirit.

Snapshot `{tick:int,time:float,players:Dictionary,enemies:Dictionary,drops:Dictionary,gathers:Dictionary}`. Player values `{id,name,pos,yaw,hp,max_hp,energy,max_energy,level,xp,next_xp,gold,points,attributes,inventory:Array[String],equipment:Dictionary,quests:Dictionary,cooldowns:Dictionary,action:String,action_time:float,action_duration:float,ward:float,dead:bool,grounded:bool,potions:int,speed:float}`. Inventory contains catalog item IDs. Equipment keys weapon/chest/ring. Quest entries `{state:"active"|"complete",progress:int}`. Enemy values `{id,kind,name,level,pos,yaw,hp,max_hp,action,action_time,action_duration,dead,respawn:float}`. Drop values `{id,pos,gold,item,owner:int}`. Gather values `{id,pos,available:bool}`. `events` are bounded structured dictionaries `{type,text,actor,target,pos,value}`.

`session.gd` Node is named `Session` directly under the main scene. Signals `updated(state:Dictionary)`, `notice(text:String)`, `disconnected(reason:String)`, `event_received(event:Dictionary)`. Fields `state`, `local_id:int`, `mode:String`, `realm`, `status:String`. Methods `start_solo(name:String) -> Error`, `host_game(name:String,port:int=24572) -> Error`, `join_game(name:String,address:String,port:int=24572) -> Error`, `start_dedicated(port:int=24572) -> Error`, `send_input(command:Dictionary)`, `command(command:Dictionary)`, `stop()`, `save_profile()`. Server snapshots at 15Hz, simulation at 30–60Hz, client input at 30Hz. Same scene-node path in all network processes. Save host-scoped profiles separately from old game saves. No public authentication claims. Preserve and test reconnect tokens privately; don't send tokens in snapshots. Local data cannot grant a client's arbitrary stats. Use atomic save replacement and validate loads.

`world.gd` Node3D is presentation and third-person input only. Signals `input_changed(command:Dictionary)`, `action_requested(command:Dictionary)`, `target_changed(id:String)`, `interaction_requested(id:String,kind:String)`. Public `local_id:int`, `state:Dictionary`, `target_id:String`, `camera:Camera3D`, `controls_enabled:bool`, `set_snapshot(snapshot:Dictionary,player_id:int)`, `select_target(id:String)`, `nearest_interaction() -> Dictionary`, `set_panel_open(open:bool)`. Root connects input/action to session. Camera starts behind hero looking north along -Z, perspective 60–65 degrees, orbit with RMB/LMB, wheel zoom, camera-relative WASD, Space physical jump, Tab hostile cycle, F interaction. No pointer capture while a panel is open; release on focus loss/Esc. Skills 1–5 routed by root HUD so avoid double execution. Presentation follows confirmed simulation; local visual interpolation/prediction must reconcile. Character +Z faces movement/target. The source contains no jump clip; do not invent that claim. Genuine roll/cast/death weapon visibility policy preserved.

World should supply `create_character_preview() -> Node3D` or a separate `avatar.gd` class for the root's actual animated character preview. Do not import `game/redesign` at runtime. World should accept `set_snapshot` before/after ready safely, draw target and danger ground indicators, names/health, animate existing mara.glb and appropriate enemies, show confirmed VFX via `show_event(event:Dictionary)`. Native GL Compatibility, deterministic landmarks and distant horizon. No isometric camera.

Root writes `main.gd`, `hud.gd`, new entry scene/project settings and documents/release evidence. Core agent owns `realm.gd`, `session.gd`, rules/network tests. World agent owns `world.gd`, `avatar.gd`, environment/presentation helpers. Catalog changes must be agreed through root to avoid collisions.
